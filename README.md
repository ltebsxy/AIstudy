# AI-StudyDesk

一个简单的 AI 学习与做题桌面软件，面向 Windows，无需登录软件账号。

## 功能

- 自行创建或导入课程，支持文字、图片和 LaTeX 数学公式。
- 主界面使用可嵌套的普通文件夹，课程模式与读写模式各有独立目录，支持卡片和列表视图。
- 解答题、单选题、多选题和填空题；选择、填空可直接在题目窗口作答。
- 阅读知识点后开始练习，可打开 OneNote、指定程序或本地文件。
- 独立读写模式：内置阅读 PDF、图片、TXT / Markdown，直接手写批注并截图提问。
- 未设置外部做题软件时默认打开内置写字板，支持画笔、橡皮、撤销、重做和笔迹自动保存。
- 内置写字时题目显示在画布上；使用外部软件时显示置顶题目窗口。作答按题号保存，最后一题完成后进入提交页。
- 导出老师批改材料，或使用自己配置的 AI 批改。
- 可移动、可调整大小的 AI 聊天窗口；划选知识点添加片段。
- API 与 Harness 分开配置；支持兼容 Chat Completions 的服务及自定义 HTTP 桥接。
- 聊天记录本地分页加载，支持压缩上下文；API 支持清除上下文。

## 启动与构建

代码仓库提供源码；安装包通过 Releases 单独发布。源码和安装包均不包含个人课程、API Key 或聊天记录。新安装时课程列表为空，请自行创建或导入。

Windows 上安装 Node.js 22 或更高版本后，在仓库根目录打开终端：

```powershell
cd source
npm ci
npm run vendor:math
npm run vendor:reader
npm start
```

日常双击根目录 **Start.cmd** 直接运行最新源码（需先安装上述依赖），无需重新封装。明确需要安装包或准备上传 GitHub 时构建（在 source 目录运行）：

```powershell
npm run dist
```

从 **0.1.4** 起软件更名为 **AI-StudyDesk**，使用淡绿色书本与代码图标。程序名为 `AI-StudyDesk.exe`，安装包为 `AI-StudyDesk-Setup-0.1.4.exe`。源码使用 **Start.cmd** 启动，构建文件位于 `app/`。历史版本保留原下载文件名；已有用户数据目录继续沿用。

## 读写与作答

- 主界面上方切换 **课程模式** / **读写模式**。两者的文件夹、上次位置及显示方式独立保存，可用工具栏切换卡片和列表视图。列表显示名称、修改日期、类型和大小，点击列标题可排序；虚拟课程及文件夹的大小显示“—”。
- 新建入口统一放在文件列表上方工具栏：**新建文件夹**、**新建课程**（课程模式）或 **导入文件**（读写模式）。文件夹可嵌套、重命名及移动，课程和文件通过“移动到…”调整位置；只有空文件夹可删除。
- **读写模式**：导入文件后点击“进入读写”，用内置阅读器打开应用保存的副本，文件沿左侧连续排列，右侧可自由书写；右上角设置可调文件宽度、左侧留白和页间距。写字窗口内的浮窗只显示 AI 问答；截图加入提问，不会换题或进入提交页。文件全文不会自动发送给 AI，请截图选取所需内容。课程卡片的“开始学习”只进入知识点与做题流程。
- **文件与笔记**：PDF、PNG / JPG / WebP / GIF / BMP、TXT / Markdown 均可使用画笔、橡皮、撤销与重做。原文批注和旁侧笔记放在同一连续画布上，调整文件大小时批注随原文变化；右下角“AI 问答”用于打开或关闭 AI 窗口，默认收起，开关保留聊天草稿；浮窗可拖动、调整大小，全屏提问不切换系统窗口；底部截图按钮左侧可切换 AI 模型；需要图片时在 AI 窗口使用“截图提问”。Markdown 当前按纯文本显示，GIF 显示首帧。PDF 上限 100 MB、图片 30 MB、文本 5 MB，最多 5000 页。
- **选择与填空**：编辑课程时设置题型、选项或填空标签；练习时直接勾选或填写，点击“完成”继续。窗口作答在当前练习中保留，只有完成最后一题才进入提交页，支持直接 AI 批改和导出老师批改包。
- **内置写字板**：课程未配置外部工具时自动打开，也可从解答题的“打开写字工具”进入。题干、公式、图片及选择／填空控件显示在画布上，题号菜单可切换题目。AI 问答与读写模式相同，默认收起、按需打开。画布铺满窗口，顶部悬浮工具栏提供画笔、荧光笔、橡皮、拖动、撤销/重做；颜色和粗细在工具栏“···”中设置。无翻页和画布缩放，新空白画布初始只覆盖窗口，画笔／荧光笔接近底部时才向下增加空白，上方与左右不扩展；滚动、拖动和橡皮不增加空白；接近底部约 20% 区域时增加约一屏空间，点击及抬笔均不自动滚动画面，不预置超长空白。画笔使用曲线平滑与压感渐变。滚轮滚动、手形工具拖动，右上角可回到起点。笔迹和阅读位置自动保存，重启恢复。底部提供“上一题、下一题、截图答案”；由你框选答案截图并按题号保存，完成最后一题进入提交页。原有 OneNote、文件及指定程序配置仍可使用。

在“设置 → 默认写字程序”选择内置写字板、OneNote 页面或自定义 `.exe` 程序。新建及导入课程默认使用这个设置；已有课程可在编辑页选择“使用默认程序”，也可为单门课程单独指定。读写模式始终使用内置文件与笔记工具。

## AI 设置

左下角打开“设置 → AI 设置”：

- **API**：填写服务地址、模型和自己的 Key；可用 DeepSeek 模板快速填写地址与模型。模型是否支持截图或 PDF 取决于对应服务。
- **系统提示词**：在 API 区域编辑，保存后下一次 API 请求生效；支持恢复默认。该设置不修改 Harness 代理自身的提示词。
- **Harness**：**存在诸多问题，建议不使用。目前暂不维护。** 可配置 Codex 或 HTTP 桥接，现有功能暂时保留。

AI 调用会将本次问题、选取片段、相关历史及所附图片/文件发送到你配置的服务。AI 批改会发送本次批改材料；普通离线阅读和做题无需 AI。

### 接入 Codex 等 Harness

> **存在诸多问题，建议不使用。Harness 目前暂不维护，以下接入说明仅供参考。**

**目前仅测试过 Codex（GPT 模型）。** 其他 Harness 可使用 HTTP 桥接，兼容性尚未验证。本节指本机 Codex 桌面版；普通 ChatGPT 网页聊天无法替你启动本机软件。

#### 将本段复制给 Codex

先安装并登录 Codex 桌面版。在一个用于启动软件的 Codex 任务中，完整复制并发送下面这段文字，无需填写 API Key 或连接参数：

```text
请帮我启动 Windows 上的“AI-StudyDesk”，接入本机 Codex，完成以下步骤：

1. 自动定位程序：优先检查当前项目根目录的 Start.cmd 和 app/win-unpacked/AI-StudyDesk.exe；安装版可通过“AI-StudyDesk”的快捷方式、正在运行的 AI-StudyDesk.exe 路径或 Windows 安装信息定位。如果仍找不到，请让我选择程序文件。
2. 检查你当前执行环境中的 CODEX_APP_TOOLS_PIPE_PATH、CODEX_THREAD_ID，以及桌面随附的 codex-app-tools 是否可用。只报告可用状态，连接信息仅用于本次进程继承。
3. 如果 AI-StudyDesk 已打开，提醒我保存未发送的草稿和进行中的练习，再正常退出旧进程。随后直接从你当前执行环境启动 Start.cmd 或 AI-StudyDesk.exe，继承当前环境，避免重复启动多个实例。
4. 验证桌面连接能够读取已有 Codex 任务。已有学习任务沿用原选择；尚未选择时，指导我在 AI-StudyDesk 左下角“设置 → AI 设置”中选择 Harness → Codex → 刷新任务 → 选择学习任务 → 保存设置。学习任务应与当前负责启动软件的任务分开。
5. 请让我从 AI-StudyDesk 发送一条测试问题，并确认能收到回复。若连接不可用，说明具体原因和下一步；不要把手动复制发送的结果当成自动连接成功。

请保留现有课程、密钥和聊天记录；连接环境仅在运行时继承，不保存到启动文件或配置中。若需要新建学习任务，请先让我决定。
```

设置保存后，在聊天窗口选择 **Codex** 即可提问。Codex 桌面版更新或重启后，如果自动连接失效，再复制上面这段文字，让它重新启动 AI-StudyDesk。普通双击启动 AI-StudyDesk 可能缺少自动转发所需的环境，进入“在 Codex 中继续”的手动模式。

#### 其他 Harness（未验证）

在“设置 → AI 设置 → Harness”选择 **自定义 Harness（HTTP 桥接）**，填写代理名称、桥接地址、会话 ID，以及桥接服务需要的独立访问令牌。桥接服务需接收 `{ sessionId, message, attachments, history }`，返回 `{ "reply": "回复文本" }`。具体地址和令牌由你使用的桥接服务提供；仅填写名称不能建立连接。

## 本地数据

分区、课程归属、读写文件索引及上次选区自动保存在应用目录的 `data/library.json`，导入的文件副本保存在 `data/documents/`，读写批注和空白笔记保存在 `data/annotations/`。当前便携工程对应 `app/data/`（与 `win-unpacked/` 并列），安装版对应安装目录下的 `data/`。备份时请完整保留 `data/`；应用目录需要可写权限。这些个人文件不会打入安装包或上传到仓库。

旧“书籍／类型”索引会自动迁移为普通文件夹，并先保存 `data/library-v1.backup.json`。原结构分别保留在两个独立目录中，已有课程、PDF 身份及归属保留，之后的修改互不影响。

课程、连接设置、截图和聊天记录保存在 `%APPDATA%\study-desk`。密钥使用系统加密保存在本机，不写入源码或回传界面。仓库 `.gitignore` 排除个人数据和构建输出；请勿手动强制提交这些文件。

“清除上下文”让之后的 API 请求不再包含旧历史和摘要，**保留本地聊天记录**。
