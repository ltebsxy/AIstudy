# AI-StudyDesk

一个简单的 AI 学习与做题软件，提供 Windows 桌面版与 Android 测试版，无需登录软件账号。

## 下载 0.2.3

在 [0.2.3 发布页](https://github.com/ltebsxy/AIstudy/releases/tag/v0.2.3) 下载：

- Windows 64 位：`AI-StudyDesk-Setup-0.2.3.exe`。安装后打开 `AI-StudyDesk.exe`，安装时可选择创建桌面快捷方式。
- Android 9 及以上：`AI-StudyDesk-Android-0.2.3.apk`。英语阅读专用测试版，支持文章/文件夹导入、双击离线查词、短语查询、主动 AI 翻译和阅读笔记；不包含课程作答、编程、手写画布或聊天批改。尚未真机验证，详见 [安卓版说明](android/README.md)。
- `SHA256SUMS.txt`：安装包校验值。对应源码可在发布页下载。

两个版本均不预装个人课程或阅读文章，不包含 API Key、账号凭据、聊天、截图或笔记。首次使用请自行导入材料。

## 功能

- 自行创建或导入课程，支持文字、图片和 LaTeX 数学公式。
- **设置 → 外观** 可选择浅色、夜间模式或跟随系统，自动保存并同步主界面、画布和 AI 浮窗。夜间模式调整 PDF／文本和深色笔迹的显示配色，文件原件与保存的笔迹颜色不变，图片保留原色。
- 编程课程可导入带题目注释的代码文件，在独立工作区练习、与 AI 讨论代码并预览提交。
- 主界面使用可嵌套的普通文件夹，课程模式与读写模式各有独立目录，支持卡片和列表视图。
- 解答题、单选题、多选题和填空题；选择、填空可直接在题目窗口作答。
- 阅读知识点后开始练习，可打开 OneNote、指定程序或本地文件。
- 独立读写模式：内置阅读 PDF、图片、TXT / Markdown，直接手写批注并截图提问。
- 未设置外部做题软件时默认打开内置写字板，支持画笔、橡皮、撤销、重做和笔迹自动保存；双击原文可直接修改，点击空白保存，停笔后可自动整理直线、圆和椭圆。
- 内置写字时题目显示在画布上；使用 OneNote 等外部软件时先显示可拖动的悬浮球，点击后展开题目与 AI 窗口，并可收起。截图作答仍按题号保存，最后一题完成后进入提交页。
- 导出老师批改材料，或使用自己配置的 AI 批改。
- 可移动、可调整大小的 AI 聊天窗口；划选知识点添加片段。
- API 与 ChatGPT 订阅分开配置；API 支持兼容 Chat Completions 的服务。
- 聊天记录本地分页加载，支持压缩上下文；API 支持清除上下文。

## 读写与作答

### 知识点与笔记

侧边栏的 **知识点** 是独立的笔记栏目，沿用可嵌套文件夹、卡片／列表、重命名和移动功能。点击 **新建 → 笔记**，可添加文字或图片；文字修改自动保存在本机。

在课程编辑页或学习页选择 **笔记自动保存位置**。划选课程知识点或内置做题题干后，点击 **加入笔记**；也可点击 **截图笔记** 并框选图片。内容追加到同一份课程笔记，默认保存在“知识点 / 全部笔记”。**查看笔记** 可打开已有内容，修改保存位置会移动这份笔记并保留内容。删除课程不会删除笔记。

截图笔记不会换题、提交作答或发送给 AI。笔记正文及图片位于应用的 `data/notes/`，文件夹与课程关联保存在 `data/library.json`；备份时完整保留 `data/`。旧索引升级前保留 `library-v2.backup.json`。

### 读写与课程

- 主界面上方切换 **课程模式** / **读写模式**。两者的文件夹、上次位置及显示方式独立保存，可用工具栏切换卡片和列表视图。列表显示名称、修改日期、类型和大小，点击列标题可排序；虚拟课程及文件夹的大小显示“—”。
- 文件列表顶部只保留 **新建** 和 **导入**，点击后在按钮右侧选择操作。课程可新建文件夹/课程，导入课程 JSON/课程文件夹；文件夹递归导入并保留非空目录层级。读写模式可导入文件/文件夹，知识点可新建文件夹/笔记。文件夹可嵌套、重命名及移动，只有空文件夹可删除。
- 课程和读写文件的导入窗口分别记住上次成功导入的文件夹。源码版首次默认打开 `source/output/courses/`，安装版首次打开系统下载文件夹；已记住的目录被删除时恢复默认位置。
- 读写模式可 **导入文件夹**，递归复制支持的阅读文件并保留目录层级。阅读材料包可附 `reading-pack.json`，只导入指定正文、设置文件标题及首次打开的英语阅读模式，答案与来源说明不会混入阅读列表。具体格式见 [阅读包格式](source/docs/reading-pack-format.md)。
- **读写模式**：导入文件后点击“进入读写”，用内置阅读器打开应用保存的副本，文件沿左侧连续排列，右侧可自由书写；右上角设置可调文件宽度、左侧留白和页间距。写字窗口内的浮窗只显示 AI 问答；截图加入提问，不会换题或进入提交页。文件全文不会自动发送给 AI，请截图选取所需内容。课程卡片的“开始学习”只进入知识点与做题流程。
- **文件与笔记**：PDF、PNG / JPG / WebP / GIF / BMP、TXT / Markdown 均可使用画笔、橡皮、撤销与重做。原文批注和旁侧笔记放在同一连续画布上，调整文件大小时批注随原文变化；右下角“AI 问答”用于打开或关闭 AI 窗口，默认收起，开关保留聊天草稿；浮窗可拖动、调整大小，全屏提问不切换系统窗口；底部截图按钮左侧可切换 AI 模型；需要图片时在 AI 窗口使用“截图提问”。Markdown 当前按纯文本显示，GIF 显示首帧。PDF 上限 100 MB、图片 30 MB、文本 5 MB，最多 5000 页。
- **选择与填空**：编辑课程时设置题型、选项或填空标签；练习时直接勾选或填写，点击“完成”继续。窗口作答在当前练习中保留，只有完成最后一题才进入提交页，支持直接 AI 批改和导出老师批改包。
- **内置写字板**：课程未配置外部工具时自动打开。题干、公式、图片及选择／填空控件显示在画布上，题号菜单可切换题目。AI 问答与读写模式相同，默认收起、按需打开。画布铺满窗口，顶部悬浮工具栏提供画笔、荧光笔、橡皮、拖动、撤销/重做；颜色和粗细在工具栏“···”中设置。无翻页和画布缩放，新空白画布初始只覆盖窗口，画笔／荧光笔接近底部时才向下增加空白，上方与左右不扩展；滚动、拖动和橡皮不增加空白；接近底部约 20% 区域时增加约一屏空间，点击及抬笔均不自动滚动画面，不预置超长空白。画笔使用曲线平滑与压感渐变。滚轮滚动、手形工具拖动，右上角可回到起点。笔迹和阅读位置自动保存，重启恢复。底部提供“上一题、下一题、截图答案”；由你框选答案截图并按题号保存，完成最后一题进入提交页。原有 OneNote、文件及指定程序配置仍可使用。

在“设置 → 默认写字程序”选择内置写字板、OneNote 页面或自定义 `.exe` 程序。新建及导入课程默认使用这个设置；已有课程可在编辑页选择“使用默认程序”，也可为单门课程单独指定。读写模式始终使用内置文件与笔记工具。

**英语阅读模式**：在读写窗口右上角“画布设置 → 阅读模式”选择“英语阅读模式”，选择会随当前文件保存。默认使用手形工具，鼠标左键点击英语单词，在单词附近显示词性、中文释义及音标；点击外部、按 Esc 或滚动可关闭释义窗，左键拖选短语（最多 12 个词）可查看同一释义窗并高亮选词；拖动空白处或使用鼠标中键移动画布，切换画笔可继续批注。支持文字型 PDF、TXT 和 Markdown，图片及扫描 PDF 暂不支持点词。内置 ECDICT 分层词库约 6.97 MB，含 58226 个常用词、115587 个扩展词、105337 个短语和 46538 条词形映射，分别按需加载并缓存查询，完全离线，不调用 AI API，不发送文章内容。支持词形还原；未收录的单词提供拼写建议，未收录的完整短语明确展示分段释义。词库来源及许可见 [第三方许可说明](THIRD_PARTY_NOTICES.md)。

## 编程课程（开发中）

新建课程时选“编程课程”，填写知识点并导入含题目注释的 UTF-8 文本文件夹。选择入口文件；也可指定编程程序 `.exe`。未指定时，应用按入口文件类型尝试打开关联的编辑程序（Python 文件优先使用已安装的 IDLE），并始终打开工作区文件夹。文件夹上限 200 个文件、10 MB，隐藏文件、依赖与构建目录不导入。

首次进入练习会把课程文件复制到 `%APPDATA%\study-desk\programming-workspaces\课程ID`；以后继续使用已修改的工作区，不会覆盖课程原件。应用在练习时隐藏主窗口，打开工作区文件夹和可用的编程软件；系统没有关联编辑程序时，仍可从文件夹中自行选择程序。桌面悬浮球可展开 AI 问答，窗口展开时尽量放入小球所在屏幕的可用区域，收起后回到小球原位。用户自行框选的截图只作为 AI 附件。提问时发送工作区中全部可读取的文本文件（上限 12 万字符），不发送隐藏文件。API 连接可生成文件修改建议；各文件修改前后的完整内容会先显示，仅在点击“确认写入这些文件”后应用。保存外部程序中的文件后，点击悬浮窗“提交”进入预览，确认后在 `%APPDATA%\study-desk\programming-submissions` 保存快照。随后可选择 **AI 批改**，使用 AI 设置中的当前连接，发送课程原题与本次提交文件（合计上限 12 万字符），显示并保存批改结果；也可选择 **打包 ZIP**，自行选择保存位置。压缩包包含课程原题与本次提交文件，已有批改结果也会附上。两者均使用提交快照，继续修改工作区不会改变已提交内容。工作区在“设置 → 练习工作区”手动清理，删除课程不会自动清理。

## AI 设置

左下角打开“设置 → AI 设置”：

- **API**：填写服务地址、模型和自己的 Key；可用 DeepSeek、GPT-6.1 Sol、GPT-6 Sol、GPT-6 Astra、GPT-6 Luna 模板快速填写地址与模型。API 使用独立的 API 计费；模型是否支持截图或 PDF 取决于对应服务。
- **系统提示词**：在 API 区域编辑，保存后下一次 API 请求生效；支持恢复默认。ChatGPT 订阅可单独设置提示词。

AI 调用会将本次问题、选取片段、相关历史及所附图片/文件发送到你配置的服务。AI 批改会发送本次批改材料；普通离线阅读和做题无需 AI。

### 旧代理配置迁移

Harness 接入已移除。旧版本选用该方式时，升级后显示“请选择 AI 连接”，需要在设置中主动选择 API 或 ChatGPT 订阅；不会自动调用其他服务。旧配置、加密凭据及聊天记录保留在本机，但旧代理连接不再执行。课程、笔记和材料不受影响。

### 释义窗中的 AI翻译与笔记

释义窗右下角可主动点击 **AI翻译**，使用设置中的 API 或 ChatGPT 订阅连接翻译当前单词/短语，不附带文章全文或聊天历史。点击 **加入笔记** 保存词语、本地释义和已显示的 AI 译文；桌面版按文章追加到“知识点”中的同一份阅读笔记，默认保存于知识点根目录，可再移动到文件夹。安卓阅读笔记可从顶部“笔记”查看。

## 本地数据

分区、课程归属、读写文件索引及上次选区自动保存在应用目录的 `data/library.json`，导入的文件副本保存在 `data/documents/`，读写批注和空白笔记保存在 `data/annotations/`。当前便携工程对应 `app/data/`（与 `win-unpacked/` 并列），安装版对应安装目录下的 `data/`。备份时请完整保留 `data/`；应用目录需要可写权限。这些个人文件不会打入安装包或上传到仓库。

编程练习工作区、提交快照、聊天记录、课程数据与密钥配置保存在 `%APPDATA%\study-desk`，不放入构建目录。工程根目录的 `temp/` 仅用于临时文件，内容不会纳入版本控制。

旧“书籍／类型”索引会自动迁移为普通文件夹，并先保存 `data/library-v1.backup.json`。原结构分别保留在两个独立目录中，已有课程、PDF 身份及归属保留，之后的修改互不影响。

课程、连接设置、截图和聊天记录保存在 `%APPDATA%\study-desk`。密钥使用系统加密保存在本机，不写入源码或回传界面。仓库 `.gitignore` 排除个人数据和构建输出；请勿手动强制提交这些文件。

“清除上下文”让之后的 API 请求不再包含旧历史和摘要，**保留本地聊天记录**。

## 开发

### ChatGPT 订阅连接

本地开源版可在“设置 → AI 设置 → ChatGPT 订阅”通过 **Continue with ChatGPT** 登录、授权并选择可用模型，再保存设置。资格、限额及点数设置由 OpenAI 决定；不自动切换 API 计费。支持 AI 问答、压缩／清除上下文和 AI 批改。操作、数据处理、退出及接入范围见 [ChatGPT 订阅说明](source/docs/chatgpt-subscription.md)。
