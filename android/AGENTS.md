# 安卓工程要求

- 安卓版已改为英语阅读专用，不恢复课程作答、编程、手写画布、聊天/批改或桌面外部工具。
- 保留文章/文件夹导入、离线双击查词、选区短语查询、阅读进度、外观排版，以及释义窗“AI翻译”和“加入笔记”。AI 仅主动点击时发送当前词语；普通查词离线。阅读笔记与文章分开保存，删除文章不删除笔记。
- 沿用包名和内部数据目录。旧课程、手写笔记和密钥数据保留，不因功能精简自动清空；阅读位置兼容旧 canvas.scroll。
- 仅用户要求打包/上传时构建 APK，日常修改源码和少量定向验证；android/ 不创建 npm 工程，依赖沿用 source/。
- 旧发布 APK 不代表当前源码功能。未连接真机时明确说明验证范围，不将 Chrome 触控仿真称为真机验证。
