# 用户确定的课程与产品要求

## 写字与读写画布

- 写字板铺满整个窗口，顶部只放紧凑的悬浮工具栏；不要恢复翻页、画布缩放、固定纸页或手动扩展按钮。
- 画布初始只覆盖窗口，仅画笔／荧光笔进入底部约 20% 区域时向下扩展约一屏；不向上、左、右扩展，滚动、拖动和橡皮不触发扩展，不能预置一段超长空白；笔迹使用世界坐标，不能靠创建超高 Canvas 实现。
- 画布扩展只增加可滚动范围，点击、书写、抬笔都不得自动移动视口；题目使用轻淡的边框区域，分值标签不拆行。
- 除非用户要求上传 GitHub，否则不封装；使用根目录 Start.cmd 运行最新源码。
- 读写文件在左侧连续展示，旁侧可写笔记；文件宽度、左侧留白和页间距集中在右上角设置中，调整时原文批注随文件变化。保存笔迹、显示设置和阅读位置，并兼容已有笔迹。

- 内置做题的题干、公式、图片、选择与填空控件显示在画布上；内置做题与读写的 AI 问答采用写字窗口内可拖动、可调大小的浮窗，默认关闭，不能因切换聊天焦点退出全屏或激活任务栏。外部写字程序继续使用独立题目悬浮窗。
- 读写右下角“AI 问答”仅用于开关 AI 窗口，保留草稿，不自动截图；画笔使用平滑曲线和压感渐变。

## 课程编写

- 使用用户指定的教材版本；未指定时先明确采用的版本。
- 定义、符号约定与适用条件以该版本原书为准。核对原书内容，不只核对目录；不能用自行选取的定义或更强条件替代原书而声称一致。
- 无法取得某一定义的原书依据时，明确说明并请求对应页，不能凭记忆声称已核对。必要补充须与原书定义分开标识。
- 语言简洁，保留定义的必要条件、核心结论和必要例题，避免重复说明。精简学习流程与步骤。
- 数学使用已有 LaTeX 渲染，练习答案和评分项仅进入批改材料。

## 学习交互与 AI

- Harness 暂不维护；在设置入口与配置区域提示“存在诸多问题，建议不使用”。除非用户另行要求，不主动扩展或维护 Harness 功能。
- 普通做题截图对应当前题号，确认后保存并继续；只在完成最后一题时自动进入提交页。AI 聊天模式下的截图只加入聊天输入，不换题、不标记完成、不进入提交页。
- 内置做题底部提供“上一题、下一题、截图答案”；下一题在末题进入提交页，截图答案由用户自行框选，不自动导出整个笔迹画布。
- 重拍替换对应题目的截图，其他题不受影响；截图和批改材料必须保留题号对应。
- 知识点页允许划选正文后“加入侧边聊天”；输入栏显示“片段 1”等标签，悬停可查看原文，发送问题时附上，不自动携带整节知识点。知识点 AI 聊天始终采用可移动、可调整大小的浮动窗口，不挤压正文。
- 固定 AI 提示仅保留“解释知识点，语言精简”或“题目评分，指出问题，语言精简”，附上必要问题或材料位置。不要重新添加长篇角色、流程和输出格式要求。
- API 与 Harness 在左下角设置中独立配置，API 支持 DeepSeek 等 Chat Completions 兼容服务；Harness 单独选择 Codex 或 HTTP 桥接。不要将 API Key 作为 Harness 凭据，或恢复聊天内的任务下拉框。
- 聊天按课程和连接保存在本地，打开默认最近 5 条，向上每次加载 5 条；密钥仅在主进程解密，不明文保存或回传前端。侧边导航支持收起并记住状态。
- 聊天发送按钮左侧允许切换 API/Harness；显示模型名或 Harness 名称，不显示 Codex 任务列表。切换保留草稿、片段与待发送截图。配置模板区分展示名称与实际 API 模型 ID，新增或更新模板须核对服务商官方文档。
- 内置写字聊天的模型切换放在底部截图按钮左侧，截图按钮保持紧凑；外部做题聊天的模型切换位于左上角，不保留“设置连接”按钮。知识点与做题聊天提供压缩上下文：API/HTTP 用简洁摘要与最近四条消息替代发送历史，保留本地原记录；压缩专用提示只要求归纳关键学习信息。Codex 调用原生压缩接口，等待完成事件，桌面占用时如实说明限制。
- API 从首次提问起附带一条简短的系统提示，要求自然友好、简洁清楚、数学严谨与 LaTeX 公式。无状态请求沿用同一条开头提示，不重复追加到消息记录，不改变 Harness 提示。API 聊天提供“清除上下文”，清除发送历史及摘要，保留本地记录、草稿、片段和待发送截图；重启或再次压缩不能恢复已清除的旧上下文。
