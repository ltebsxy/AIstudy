# 用户确定的课程与产品要求

- 本项目采用 `GPL-3.0-only`，完整条款位于根目录 `LICENSE`。保留第三方原有许可；新增依赖或复制外部代码时核对兼容性及声明。构建须附带项目许可证、第三方许可说明及对应源码获取方式。

- 软件名称统一为 `AI-StudyDesk`，界面、窗口标题、安装包与说明文档使用同一名称。安装版保留 `local.studydesk.app` 作为兼容标识，源码版使用 `local.studydesk.source`，避免与旧安装版合并任务栏图标；都沿用原 `study-desk` 数据目录，改名不能使已有数据丢失。
- 应用图标保持书本、屏幕、代码符号与星星构图和透明背景，主色为淡绿色，减少周围留白以增强小尺寸辨识度。主要图形使用极细的深灰黑描边，以用户最新边缘截图的背景取色 `#1B1B1B` 为准；使用 `assets/icon.svg` 的统一轮廓生成 PNG/ICO，界面、任务栏及快捷方式同步使用此图标，不添加阴影或浅灰光晕。左上角品牌区无背景框，适当放大图标；课程导航和模式切换等选中状态使用中性灰底。Windows 窗口与快捷方式使用按图标内容生成的缓存路径，防止任务栏复用旧图标。
## 写字与读写画布

- 内置写字板双击已有笔记文字、TXT/Markdown 正文或新增文字即可原位编辑，无需切换 T；点击空白处保存并退出，不落笔或新建文字。T 工具仍用于在空白处添加文字。原位编辑不显示修改框、边框、标题或完成按钮，失焦自动保存；点击空白处创建可拖动的文字框并自动保存；PDF/图片保持原件，可在画布加文字批注。默认新文字框 26px，笔记正文按 36px、文本文件按 28px 的文档坐标绘制，默认文档区域占窗口约 80% 并水平居中；已有显示设置保留，可通过“恢复文件显示”采用新默认布局。
- 画笔停止约 1.8 秒后保守拟合直线、圆和椭圆，支持按住停留及抬笔后停留；继续书写或切换工具取消等待，无法明确识别则保留原笔迹。画笔设置可关闭自动整理；本次会话内撤销整理先恢复原笔迹，不能直接丢掉整笔。识别在本机完成，不调用 AI。画布手势按发起 pointerId 隔离，其他指针的移动、抬起与取消不得污染或截断当前笔画；原始和合并绘图样本必须处于按下状态，悬停不应改变笔画。

- 写字板铺满整个窗口，顶部只放紧凑的悬浮工具栏；不要恢复翻页、画布缩放、固定纸页或手动扩展按钮。
- 画布初始只覆盖窗口，仅画笔／荧光笔进入底部约 20% 区域时向下扩展约一屏；不向上、左、右扩展，滚动、拖动和橡皮不触发扩展，不能预置一段超长空白；笔迹使用世界坐标，不能靠创建超高 Canvas 实现。
- 画布扩展只增加可滚动范围，点击、书写、抬笔都不得自动移动视口；题目使用轻淡的边框区域，分值标签不拆行。
- 日常不封装；仅在用户明确要求打包或上传 GitHub 时构建安装包。使用根目录 Start.cmd 运行最新源码。
- 读写文件在左侧连续展示，旁侧可写笔记；文件宽度、左侧留白和页间距集中在右上角设置中，调整时原文批注随文件变化。保存笔迹、显示设置和阅读位置，并兼容已有笔迹。

- 内置做题的题干、公式、图片、选择与填空控件显示在画布上；内置做题与读写的 AI 问答采用写字窗口内可拖动、可调大小的浮窗，默认关闭，不能因切换聊天焦点退出全屏或激活任务栏。外部写字程序继续使用独立题目悬浮窗。
- 读写右下角“AI 问答”仅用于开关 AI 窗口，保留草稿，不自动截图；画笔使用平滑曲线和压感渐变。
- 读写模式可在右上角画布设置选择英语阅读模式，按文件保存选择。默认使用手形工具：鼠标左键点词在窗口内显示词性、中文释义和音标，左键拖选短语显示同一释义窗并高亮选词，拖动空白处或使用鼠标中键移动画布，切换画笔可继续批注。支持文字型 PDF、TXT 和 Markdown；使用按需加载的内置 ECDICT 分层词库离线查询；常用词、扩展词和短语分别按需加载，整段未收录时明确标注分段释义，普通查词不调用 AI API。释义窗右下角提供“AI翻译”和“加入笔记”：仅主动点击 AI翻译时发送当前词语，不附带全文/历史；加入笔记保存选词、本地释义及已显示的 AI 译文，按文章追加到知识点的阅读笔记，与课程笔记关联分开。

## 课程编写

- 使用用户指定的教材版本；未指定时先明确采用的版本。
- 定义、符号约定与适用条件以该版本原书为准。核对原书内容，不只核对目录；不能用自行选取的定义或更强条件替代原书而声称一致。
- 无法取得某一定义的原书依据时，明确说明并请求对应页，不能凭记忆声称已核对。必要补充须与原书定义分开标识。
- 语言简洁，保留定义的必要条件、核心结论和必要例题，避免重复说明。精简学习流程与步骤。
- 数学使用已有 LaTeX 渲染，练习答案和评分项仅进入批改材料。

## 学习交互与 AI

- 桌面读写文件具有与课程相同风格的编辑页：修改名称、简介、阅读模式，TXT/Markdown 可编辑正文，PDF/图片可更换原文；始终修改应用内副本，保留已保存的笔记。读写编辑页和画布设置可指定一份已有笔记，或指定文件夹自动建立阅读笔记；文字选取、词语释义和截图都追加到同一目标。切换目标不搬走已收录内容。知识点笔记默认在读写式连续画布打开，支持原有文字/图片、手写和自动保存；编辑内容入口保留文字/图片管理，旧笔记无需迁移。笔记图片夜间保持原色。

- 侧边栏“知识点”使用独立文件夹树，文件称为“笔记”；支持卡片/列表、新建、重命名、移动和删除。笔记保存用户选中的文字及框选截图，不自动收集全文、聊天或手写作答。课程编辑页和学习页可选择该课程的笔记保存文件夹；同一课程的内容追加到同一笔记，修改位置移动现有笔记。笔记文字与图片保存在应用 `data/notes/`，位置与课程关联保存在 library.json，旧索引升级前备份；删除课程不删除笔记。“截图笔记”与截图作答、AI 附件分别处理，不换题、不提交、不调用 AI。

- 外观设置提供浅色、夜间与跟随系统，保存到本地 preferences.json；首次绘制前应用主题，切换和系统外观更新同步主界面、写字窗口、内嵌聊天及桌面浮窗。夜间画布与 PDF／文本采用深色配色，深色笔迹显示为浅色，但不得修改保存的笔迹或文件原件；图片保持原色。
- 课程与读写文件导入分别记住上次成功导入的目录；源码版首次默认使用 `source/output/courses/`，安装版使用系统下载目录。取消或导入失败不更新记录，目录失效时恢复默认位置。
- 内容列表统一使用“新建”“导入”入口，点击后在按钮右侧显示选项，再进入编辑或文件选择。课程支持导入单个课程 JSON 或整个课程文件夹；文件夹递归导入课程 JSON，保留非空层级并放入当前位置，不覆盖已有课程。整批验证后再保存，跳过非课程内容与符号链接。
- 读写支持导入文件夹，保留非空目录层级，复制文件到应用数据目录；可使用 `docs/reading-pack-format.md` 定义的 reading-pack.json version 1 清单只导入正文，并设置首次打开的英语阅读模式。导入失败不留下部分材料；跳过符号链接，不允许清单引用包外文件。配套词表与覆盖统计留在阅读材料包内，不随应用发布。
- 编程练习确认提交后可选择 AI 批改或打包 ZIP。两者使用本次提交快照；AI 同时获得课程原题与作答文件，批改结果保存在快照目录，打包时附上已有结果。不得用继续编辑的工作区替换已提交内容。
- 桌面悬浮窗展开时尽量放入小球所在屏幕的可用区域，位置可与小球不同；收起后恢复小球原位，展开后的窗口拖动不改变小球位置。
- Harness 接入已按用户要求移除，禁止恢复 Codex 任务、桌面转发或 HTTP 桥接入口。旧连接进入未配置状态，需用户主动选择 API 或 ChatGPT 订阅，不得自动转发或付费降级；保留旧配置、加密凭据和聊天文件。
- 普通做题截图对应当前题号，确认后保存并继续；只在完成最后一题时自动进入提交页。AI 聊天模式下的截图只加入聊天输入，不换题、不标记完成、不进入提交页。
- 内置做题底部提供“上一题、下一题、截图答案”；下一题在末题进入提交页，截图答案由用户自行框选，不自动导出整个笔迹画布。
- 重拍替换对应题目的截图，其他题不受影响；截图和批改材料必须保留题号对应。
- 知识点页允许划选正文后“加入侧边聊天”；输入栏显示“片段 1”等标签，悬停可查看原文，发送问题时附上，不自动携带整节知识点。知识点 AI 聊天始终采用可移动、可调整大小的浮动窗口，不挤压正文。
- 固定 AI 提示仅保留“解释知识点，语言精简”或“题目评分，指出问题，语言精简”，附上必要问题或材料位置。不要重新添加长篇角色、流程和输出格式要求。
- API 与 ChatGPT 订阅在左下角设置中独立配置，API 支持 DeepSeek 等 Chat Completions 兼容服务；不显示外部代理任务下拉框。
- 聊天按课程和连接保存在本地，打开默认最近 5 条，向上每次加载 5 条；密钥仅在主进程解密，不明文保存或回传前端。侧边导航支持收起并记住状态。
- 聊天发送按钮左侧允许切换 API/ChatGPT 订阅；显示对应模型名。切换保留草稿、片段与待发送截图。配置模板区分展示名称与实际 API 模型 ID，新增或更新模板须核对服务商官方文档。
- 不同模式的 AI 悬浮窗共用 ui-tokens.css、chat-layout.css 与 chat-ui.js：统一标题栏、消息气泡、输入框右侧的发送/停止图标，模型切换统一放在输入栏下方、紧凑截图按钮左侧。知识点没有截图提问时只显示模型栏；返回题目、提交、修改建议等模式专属操作另放一行，不保留“设置连接”按钮。知识点与做题聊天提供压缩上下文：API/ChatGPT 订阅 用简洁摘要与最近四条消息替代发送历史，保留本地原记录；压缩专用提示只要求归纳关键学习信息。
- API 从首次提问起附带一条简短的系统提示，要求自然友好、简洁清楚、数学严谨与 LaTeX 公式。无状态请求沿用同一条开头提示，不重复追加到消息记录，ChatGPT 提示词独立配置。API 聊天提供“清除上下文”，清除发送历史及摘要，保留本地记录、草稿、片段和待发送截图；重启或再次压缩不能恢复已清除的旧上下文。

- ChatGPT 订阅连接遵循 OpenAI 本地开源 Sign in with ChatGPT 规范（见 docs/chatgpt-subscription.md）；使用官方浏览器授权、PKCE、state/nonce/JWKS 验证及实际权限检查，凭据仅主进程加密保存到用户数据目录；不使用 Cookie、backend-api、共享账号代理或自动 API 计费降级。账号／模型上下文独立，界面提供管理额度和退出；仅公开 Responses 接口 store:false / stream:true，收到 response.completed 才视为成功。商业化、托管或规范变更前重新核对官方资格与政策。
