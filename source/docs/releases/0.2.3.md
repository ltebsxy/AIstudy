# AI-StudyDesk 0.2.3

Windows 桌面版与 Android 英语阅读测试版，2026-10-17。

## 桌面版

- 新增独立“知识点”笔记栏目，支持文件夹、文字选取、截图收录及课程/读写文件默认笔记位置。
- 笔记使用连续画布；双击已有文字原位编辑，点击空白自动保存。默认字号增大、内容居中。
- 画笔停留后保守整理直线、圆和椭圆；撤销恢复原笔迹，过滤其他指针及未按下的悬停样本。
- 增加离开写字窗口前保存确认、正文版本保留与恢复。
- “新建”和“导入”统一为右侧选项菜单；课程支持导入整个文件夹，保留目录层级。
- 各模式 AI 浮窗、控件及浅色/夜间布局统一。释义窗增加主动“AI翻译”和“加入笔记”。
- 移除 Harness 连接，仅保留用户主动配置的 API 或独立 ChatGPT 订阅。旧配置及聊天保留，需手动选择新连接，不自动切换计费方式。

## 安卓版

- 精简为英语阅读专用：文章/文件夹导入、双击离线查词、短语查询、阅读进度、外观排版和阅读笔记。
- “AI翻译”仅主动点击时发送当前词语；普通查词离线。使用自行配置的 API，不含 ChatGPT 订阅登录。
- 删除文章不删除阅读笔记；旧课程、手写及配置数据保留。沿用包名和原开发签名。
- APK 为测试版，尚未真机验证；SAF、系统选区、后台恢复及 Keystore/API 联网仍待设备确认。

## 下载和源码

- Windows 64 位：`AI-StudyDesk-Setup-0.2.3.exe`。安装后用 `AI-StudyDesk.exe` 启动，安装时可选择是否创建桌面快捷方式。
- Android 9 及以上：`AI-StudyDesk-Android-0.2.3.apk`。
- 校验值：`SHA256SUMS.txt`。
- GPL-3.0-only 完整对应源码：[v0.2.3](https://github.com/ltebsxy/AIstudy/tree/v0.2.3)，发布页亦提供源码压缩包；Android 构建需同时保留 `android/` 和 `source/`。

源码和安装包不包含个人课程、阅读材料、API Key、账号凭据、聊天、截图、笔记或本机签名密钥。

## 已知限制

图形整理历史偶发超时仍缺少原始事件证据，无法唯一归因；本版修复已复现的指针污染，并加入默认关闭的本机诊断。另一次撤销断言异常和动态替换测试处理器时的短轨迹现象尚未解释，后续通过不代表已彻底解决。独立 ChatGPT 订阅的线上授权和推理权限以 OpenAI 与账号资格为准，本次本地测试不代表线上接入成功。
